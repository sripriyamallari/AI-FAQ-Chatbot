# 🤖 AI FAQ Chatbot

An intelligent **Artificial Intelligence FAQ Chatbot** built using Python, Natural Language Processing concepts, TF-IDF vectorization, Cosine Similarity, and Streamlit.

The chatbot accepts a user's question and identifies the most relevant FAQ from a predefined collection of Artificial Intelligence questions. It then displays the corresponding answer through a simple and user-friendly web interface.

## 📌 Project Overview

The AI FAQ Chatbot is designed to provide quick answers to frequently asked questions related to Artificial Intelligence.

The project uses **TF-IDF (Term Frequency-Inverse Document Frequency)** to convert FAQ questions into numerical vectors and **Cosine Similarity** to determine which FAQ is most similar to the user's question.

## ⚙️ How It Works

1. The user enters a question.
2. The question is preprocessed and converted to lowercase.
3. FAQ questions are converted into TF-IDF vectors.
4. Cosine Similarity compares the user's question with the FAQ questions.
5. The chatbot identifies the most similar question.
6. The corresponding answer is displayed to the user.
